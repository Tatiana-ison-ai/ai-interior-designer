# 🛋️ AI-помощник дизайнера интерьера

Учебный проект по **Vibe Coding**: генератор структурированного технического задания (ТЗ) для дизайн-проекта интерьера на основе **Python 3.10+** и **OpenRouter API** без додумывания фактов.

Проект поддерживает два варианта интерфейса:
- **Streamlit** (`streamlit_app.py`) — оптимизирован для публикации на **Streamlit Community Cloud**.
- **Gradio** (`gradio_app.py`) — сохранён для отчёта и публикации на **Hugging Face Spaces**.

---

## 🎯 Назначение

Приложение помогает дизайнеру интерьера быстро превратить вводные данные клиента в структурированное ТЗ без выдумывания фактов:
- Фиксирует только введённые параметры помещения (площадь, назначение, бюджет, стиль).
- **Не додумывает** недостающую информацию (материалы, перепланировку, инженерные сети).
- Формирует отдельный акцентный блок **«Что необходимо уточнить у заказчика»** с конкретными вопросами.
- **Защита данных:** автоматически маскирует телефоны, email и паспортные данные на стороне Python до обращения к API.

## ☁️ Развёртывание на Streamlit Community Cloud

1. Загрузите файлы проекта в ваш публичный или приватный GitHub-репозиторий.
2. Перейдите на [share.streamlit.io](https://share.streamlit.io) и нажмите **New app**.
3. Выберите ваш репозиторий:
   - **Main file path:** `streamlit_app.py`
   - **App URL:** укажите желаемое имя (например, `ai-interior-assistant`).
4. В разделе **Advanced settings** → **Secrets** добавьте секретный ключ:
   ```toml
   OPENROUTER_API_KEY = "sk-or-v1-ваш-секретный-ключ"
   ```
5. Нажмите **Deploy!** — Streamlit установит зависимости из `requirements.txt` и запустит приложение.

## 🚀 Быстрый запуск локально

1. Убедитесь, что установлен Python 3.10 или выше:
```bash
python --version
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Задайте переменную окружения с ключом OpenRouter:
- **Linux/macOS**:
  ```bash
  export OPENROUTER_API_KEY="<ваш_ключ_от_openrouter>"
  ```
- **Windows (PowerShell)**:
  ```powershell
  $env:OPENROUTER_API_KEY="<ваш_ключ_от_openrouter>"
  ```

4. Запустите интерфейс Streamlit:
```bash
streamlit run streamlit_app.py
```
*(Или версию Gradio: `python gradio_app.py`)*

---

## 🛡️ Безопасность и данные

- Ключ `OPENROUTER_API_KEY` считывается строго из `st.secrets` или переменных окружения и не хранится в коде.
- Приложение не запрашивает и не сохраняет персональные данные клиентов.
